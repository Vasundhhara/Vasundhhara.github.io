CLIP-Powered Fashion Search Engine

Hushh AI · 2024
CLIPMultimodalVector SearchEmbeddings

A multimodal search engine that lets users find fashion items by image or natural language — "a dress like this photo but in blue" — using CLIP embeddings and vector similarity search.

How it works

  • CLIP encodes product images and text queries into a shared embedding space, so image-to-image and text-to-image search use the same index.
  • Vector similarity search retrieves the closest catalog items in real time.
  • Served through FastAPI microservices as part of the personalization product suite.

Why it matters

Keyword search fails for style — users can rarely describe exactly what they want. Multimodal retrieval made discovery feel natural and became a flagship demo for brand partnership conversations.
