Blockchain-Based Federated Learning

A federated ML system that replaces the central aggregation server with a decentralized blockchain — model updates are coordinated through a smart contract written in Motoko and deployed on-chain, removing the single point of trust and failure in classic federated learning.

CNN X-Ray — Pneumonia Diagnosis

A deep learning model using Convolutional Neural Networks to automate pneumonia diagnosis from chest X-ray images. Trained on a labeled dataset with TensorFlow/Keras, using image-processing techniques to enhance accuracy.

Why these projects

Both explore the same question from different angles: how do you make ML trustworthy — decentralizing who controls the model, and applying it where correctness has real human stakes.
