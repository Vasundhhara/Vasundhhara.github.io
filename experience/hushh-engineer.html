Personal Knowledge Management (PKM) R&D

  • Led research and development of a PKM system integrating structured and unstructured data into an AI-driven personalized chatbot, managing architecture, testing, and deployment.
  • Designed and evaluated three retrieval architectures to improve contextual search and recommendation quality:
    • LLM-generated GraphQL queries for extracting relevant user data (GraphQL, LangChain, LLaMA, Hugging Face, Ollama, FastAPI)
    • LightRAG-based retrieval, implemented from the research paper (FastAPI)
    • GraphRAG-based retrieval over a Neo4j graph database (FastAPI, Neo4j)
  • Spearheaded deployment strategy across Vertex AI, Docker, self-hosted GPUs, Hugging Face, and GCP — balancing inference cost, latency, and scalability.

  • Built robust developer APIs with FastAPI featuring secure onboarding, real-time processes, webhooks, and notifications via Firebase Cloud Messaging.
